Gimbal

"Gimbal lock is the loss of one degree of freedom in a multi-dimensional mechanism at certain alignments of the axes. In a three-dimensional three-gimbal mechanism, gimbal lock occurs when the axes of two of the gimbals are driven into a parallel configuration, "locking" the system into rotation in a degenerate two-dimensional space." - Wikipedia

This CAD project for Hackclub Half Life is meant to act as a model of three dimentional rotations, which is something I often find myself struggling on in game design and other rendering. Therefore, having a physical model may make it somewhat easier. The design of this project was somewhat derived from a youtube video (https://www.youtube.com/watch?v=zc8b2Jo7mno) about gimbal locks, although all the work is my own. (I simply used it as a visual refrence)
Overall this project is around 200x200x250mm. It requires some glue to assemble, and I printed in PLA.
